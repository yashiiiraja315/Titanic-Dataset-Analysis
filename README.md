# Titanic Dataset Analysis

## 📌 Project Overview
This project performs Exploratory Data Analysis (EDA) on the Titanic dataset to understand passenger characteristics and survival patterns.

## 🎯 Objectives
- Analyze passenger survival patterns.
- Study the relationship between gender and survival.
- Compare survival rates across passenger classes.
- Analyze age distribution of survivors and non-survivors.
- Explore passenger fare distribution.
- Handle missing values in the dataset.
- Visualize important patterns using charts.

## 🛠️ Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab
- Jupyter Notebook

## 📊 Key Findings
- Female passengers had a higher survival rate than male passengers.
- First-class passengers had the highest survival rate.
- Third-class passengers had the lowest survival rate.
- Survivors had a slightly lower average age than non-survivors.
- Most passenger fares were concentrated in the lower fare range.

## 📈 Visualizations
The analysis includes visualizations for:
- Survival Rate by Gender
- Survival Rate by Passenger Class
- Age Distribution by Survival
- Fare Distribution

## ✅ Conclusion
The analysis shows that passenger gender and passenger class were strongly associated with survival in the Titanic dataset. Exploratory data analysis and visualization helped identify important patterns and understand factors related to passenger survival.
